# The Most Boring Object, Reviewed in One Line

[![make.fun](https://make.fun/badge.svg)](https://make.fun/competitions/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)

make.fun entry for **The Most Boring Object, Reviewed in One Line** ($2, free entry).

> The shower drain cover spends every morning catching your hair so your feet don't swim in yesterday's shampoo, and its only thanks is being lifted out, gagged at, and dropped back into the dark.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes the single-line review to `out/entry.txt` (no trailing newline, 194 characters).
